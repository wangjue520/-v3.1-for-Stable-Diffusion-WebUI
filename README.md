# -v3.1-for-Stable-Diffusion-WebUI
图像后期处理脚本 v3.1 for Stable Diffusion WebUI
这是一款为 Stable Diffusion WebUI 设计的、功能强大的图像后期处理扩展脚本。它集成了完整的图像调色和滤镜功能，让你可以在 WebUI 中一站式完成从图像生成到后期调整的全过程。

脚本提供两种工作模式：

集成流水线模式：在 txt2img 或 img2img 生成图像后自动应用调色预设。

独立调色工具：一个可以随时启动的独立界面，用于对任意图片进行实时调色和预览。

✨ 功能亮点
本脚本提供了丰富的图像调整功能，媲美专业的照片编辑软件，所有功能都集中在易于使用的Gradio界面中。

🎨 基础调色 (Basic Adjustments)
曝光 (Exposure): 调整图像的整体亮度。

对比度 (Contrast): 调整亮部与暗部的差异。

高光 (Highlights) & 阴影 (Shadows): 分别控制图像最亮和最暗区域的细节。

白色色阶 (Whites) & 黑色色阶 (Blacks): 设定图像的白点和黑点，影响整体动态范围。

饱和度 (Saturation) & 自然饱和度 (Vibrance): 增强色彩的鲜艳程度，后者能更智能地保护肤色。

色温 (Temperature) & 色调 (Tint): 调整图像的白平衡，实现冷暖色调的转变。

####🎨 单色与渐变 (Monochrome & Gradients)

双色调 (Duotone): 将图像映射到两种自定义颜色（暗部和亮部）之间，并可调整混合强度，轻松创作艺术风格的单色图片。

🔪 锐化与模糊 (Sharpen & Blur)
锐化 (Sharpen): 增强图像细节，使边缘更清晰。

高斯模糊 (Gaussian Blur): 对图像进行平滑处理。

运动模糊 (Motion Blur): 模拟物体运动或相机抖动产生的模糊效果，可自定义角度。

🎞️ 噪点与颗粒 (Noise & Grain)
多种噪点: 可添加高斯、椒盐、均匀、斑点等多种类型的噪点。

胶片颗粒 (Film Grain): 模拟老式胶片的颗粒感，增加复古质感。

滤镜与风格化 (Filters & Stylization)
素描/铅笔画 (Sketch/Pencil): 将图片转换为手绘素描风格。

边缘检测 (Edge Detection): 提取图像的轮廓。

怀旧棕调 (Sepia): 经典的复古棕色滤镜。

反色 (Invert): 反转图像颜色。

像素化 (Pixelate): 创建马赛克/像素艺术效果。

雨滴 (Raindrops): 为画面添加逼真的下雨效果。

⚙️ 工作流工具 (Workflow Tools)
预设管理: 可以将你精心调校的参数保存为预设，并随时加载使用。

独立调色工具: 无需生成图片，可直接上传本地图片进行调整和预览。

额外保存原图: 在应用后处理的同时，可以自动保存一张未经处理的原图，方便对比。

元数据记录: 应用的后处理参数会自动记录到生成图片的元数据中，方便溯源。

依赖自动安装: 首次运行脚本时，会自动检测并尝试安装所需的 Python 库 (opencv-contrib-python)。

💻 安装说明
下载 图像自动调色v3.1.py 脚本文件。

将该文件放入你的 Stable Diffusion WebUI 安装目录下的 scripts 文件夹中。

路径示例: stable-diffusion-webui/scripts/图像自动调色v3.1.py

重要: 完全重启 Stable Diffusion WebUI。

脚本首次运行时会自动检测并安装依赖库。安装成功后，你需要再次重启WebUI才能使脚本正常加载。

🚀 使用方法
本脚本提供两种核心使用模式：

模式一：集成流水线处理 (Integrated Pipeline)
此模式用于在每次生成图片后自动应用调色。

在 文生图 (txt2img) 或 图生图 (img2img) 标签页的底部，找到 脚本 (Script) 下拉菜单。

选择 图像后期处理 (v3)。

此时会展开脚本的设置界面。

勾选 启用图像后处理 复选框来激活功能。

根据你的需求调整下方的各种调色滑块和选项。

额外保存原图：如果勾选，除了生成处理后的图片，还会额外在 outputs/post-processing-extras/ 目录下保存一张原图。

点击 WebUI 的 生成 (Generate) 按钮，生成的图片将会自动应用你设置的后期处理效果。

模式二：独立调色工具 (Standalone Tool)
此模式提供一个独立的界面，可以对任意图片进行实时调色。

在 文生图 (txt2img) 或 图生图 (img2img) 标签页中，你会看到脚本区域的顶部有一个 🚀 启动独立调色工具 的按钮。

点击该按钮，会展开一个独立的UI界面。

上传图片: 在左侧的图片框中上传或拖入任何你想要处理的图片。

实时调整: 调整下方的滑块和选项，右侧的预览窗口会实时显示效果。

保存图片: 对效果满意后，点击预览图下方的 💾 保存图片 按钮，处理后的图片会保存在 stable-diffusion-webui/scripts/standalone_output 目录下，并提供下载链接。

收起工具: 点击 收起独立工具 按钮可以关闭此界面。

💾 预设管理 (Preset Management)
无论是集成模式还是独立模式，都配有预设管理功能。

保存预设:

调整好你想要的参数。

在 保存预设 文本框中输入一个预设名称（例如 电影感滤镜）。

点击 保存 按钮。

加载预设:

从 加载预设 下拉菜单中选择一个之前保存的预设。

点击 加载 按钮，所有参数将自动填充为你保存的设置。

预设文件会以 .json 格式保存在 stable-diffusion-webui/scripts/post_processing_profiles_v3 目录下。
